# Игра Камень-Ножницы-Бумага

## Описание

Консольная игра на Python, в которой пользователь соревнуется с компьютером в «Камень-Ножницы-Бумага».

## Как играть

1. Откройте терминал в папке проекта.
2. Запустите игру командой:

   ```powershell
   python game.py
3. Введите один из вариантов: камень, ножницы или бумага.
4. Чтобы завершить игру и сохранить счёт, введите выход.

## Функциональность

- случайный выбор хода компьютером;
- проверка корректности ввода пользователя;
- определение победителя каждого раунда;
- возможность играть несколько раундов подряд;
- подсчёт побед игрока и компьютера;
- сохранение результатов в файл scores.json.

##Требования

- Python 3;
- стандартные модули Python random и json.
